# Proposal: Persisted query model (judo-runtime-core-jsl)

## Why

The JSL runtime test suites and the `JSLTransformationModelLoader` sit at the end of the model build paths that
the master change `openspec/changes/persisted-query-model` (judo-ng superproject) extends with a persisted
`<name>-query.model` artifact. In this module the jsl-itest models now get the query file from the
`judo-tatami-jsl` workflow plugin, so the common `JudoRuntimeFixture` must boot its `QueryFactory` through the
shared `QueryModelLoadOrBuild` decision (strict `load` and `build`) instead of always extracting and building by
hand. `JSLTransformationModelLoader` has no file consumer, so it keeps the new stage off.

## What Changes

- `JSLTransformationModelLoader` (judo-runtime-core-jsl-guice) sets `ignoreAsm2Query=true` on the
  `DefaultWorkflowSetupParameters` it passes to `JslDefaultWorkflow`; the returned `TransformationContext` holds no
  `QueryModel`.
- jsl-itest models generated by `judo-tatami-jsl-workflow-maven-plugin` now include `<name>-query.model` next to
  the ASM, measure and expression models (no code change here; a consequence of the rank-9 workflow default).
- The common `JudoRuntimeFixture` (judo-runtime-core-jsl-itest/common) replaces its private `initQueryFactory()`
  (own `AsmJqlExtractor` + `new QueryFactory(...)`) with `QueryModelLoadOrBuild`, run in strict `load` mode and in
  `build` mode; strict `load` fails the suite instead of falling back.
- Tests: the full jsl-itest suite in strict `load`; `JSLTransformationModelLoader` asserts no `QueryModel`.
- `AGENTS.md` rows for the changed files.
- No BREAKING change in this module; it only consumes the moved and changed rank-7/8/9 APIs.

### Modified Capabilities
- `jsl-transformation`: the loader defaults the asm2query stage off.
- `test-infrastructure`: the runtime fixture obtains `QueryFactory` through the shared load-or-build decision, and
  the generated model directory includes the query file.

## Impact

- **Files:** `judo-runtime-core-jsl-guice/src/main/java/hu/blackbelt/judo/runtime/core/bootstrap/jsl/JSLTransformationModelLoader.java`,
  its test `JSLTransformationModelLoaderTest`;
  `judo-runtime-core-jsl-itest/common/src/main/java/hu/blackbelt/judo/runtime/core/jsl/fixture/JudoRuntimeFixture.java`;
  the POMs of the two modules if the new dependencies are not already transitive; the directory `AGENTS.md` rows.
- **Dependencies:** `judo-runtime-core-query` (`QueryModelLoadOrBuild`), `judo-runtime-core-guice`
  (`JudoModelLoader` digests and locator), `judo-tatami-jsl` (`ignoreAsm2Query`), `judo-tatami-asm2query`.
- **Rank:** 10, built after `judo-runtime-core` (8) and `judo-tatami-jsl` (9) in the same feature branch.
- **Rollback:** revert the fixture to its own extract-and-build; the fixture in `build` mode never opens the query
  file, and the loader flag can be dropped. No database or schema impact.
